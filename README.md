# EventFlow 🎟️

A simple multi-page event discovery and booking website built using **HTML5 and CSS3**.

Users can explore events, view event details, book tickets, and get a confirmation page.

## Features

* Event discovery homepage
* Event listing and categories
* Event details page
* Ticket booking form
* Booking confirmation
* About & contact page
* Responsive layout
* Shared CSS design

## Tech Used

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox
* Git & GitHub
